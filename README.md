# Ginikachi & Godwin · Wedding invitation draft

Tap the satin bow to part the ribbon and swing open the invitation. The page includes a countdown, expandable family and ceremony details, a diagonal wedding palette, a swipeable portrait album, a toast, and an area map for the main ceremony. Content fades and comes back into focus as guests scroll in either direction.

Run `npm run dev` with Node.js and Python 3, then open `http://localhost:3000`. The site is also directly viewable by opening `public/index.html`.

For Vercel, import the GitHub repository. The checked-in configuration serves the static `public` folder with no build step.
